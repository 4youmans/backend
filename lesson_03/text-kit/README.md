# Text Kit

**Студент:** DARKle  
**Группа:**

Набор функций для строк, чисел, проверки данных и дат. Программа печатает примеры по каждому блоку.

## Дерево проекта

- `app/main.py` - данные для примера и печать, без остальных функций.
- `app/utils/text.py` - пробелы, обрезка строки, инициалы, адрес страницы.
- `app/utils/dates.py` - чтение даты, запись даты, выходной, дни между датами.
- `app/services/statistics.py` - среднее, медиана, разброс, подсчет значений.
- `app/services/validation.py` - почта, телефон, замечания к паролю.
- `tests/` - проверки этих функций.

## Почему четыре модуля

Строки и даты можно перенести в другой проект как есть, поэтому они лежат в `app/utils/`. Расчеты и проверка данных относятся к этой программе, поэтому они лежат в `app/services/`.

`validation.py` вызывает `clean_spaces` из `app/utils/text.py`: перед проверкой почты строка очищается от лишних пробелов.

## Команды (Windows, PowerShell)

Команды запускать из папки `lesson_03/text-kit`.

```
python -m app.main
python -m unittest discover -s tests -v
```

Если команда `python` не находится, вместо нее подойдет `py`.
